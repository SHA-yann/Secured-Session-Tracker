# task manager Project

A full-stack portfolio project using:
- **Backend:** Java 17, Spring Boot
- **Frontend:** Angular 19 (standalone components)
- **Database:** PostgreSQL
- **Methodology:** Test-Driven Development (TDD)
- **Version Control:** Git (feature-branch workflow)

## Project Purpose
Demonstrate the ability to design, develop, test, and document a complete application.

## Technologies
- Java 17
- Spring Boot
- Angular 19
- PostgreSQL
- JUnit 5
- Jasmine/Karma
- Docker (optional for DB)

## Development Workflow
1. Create feature branch
2. Write tests before code (TDD)
3. Commit frequently with meaningful messages
4. Push branch and create Pull Request (PR)
5. Merge into `dev` after review
6. Merge into `main` after feature completion
